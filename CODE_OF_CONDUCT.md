# Código de conduta

Este projeto adota o **[Contributor Covenant v2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)**. O texto vinculante é o da versão publicada no link; em resumo:

- Trate todas as pessoas com respeito. Não são tolerados assédio, discriminação, insulto, ataques pessoais ou exposição de dados privados.
- Crítica é bem-vinda quando dirigida ao **código e às decisões técnicas** — com evidência, não com tom.
- Espaços do projeto (issues, PRs, discussões) são para o projeto; foco técnico.
- Interpretação e aplicação ficam com o mantenedor.

## Aplicação

Violação: reporte em **[Security → Report a vulnerability](https://github.com/Danil0ws/agentic-teams-web/security/advisories/new)** (relato privado) ou abra uma issue pedindo contato privado, sem citar pessoas ou detalhes sensíveis.

Resposta esperada: aviso, remoção do conteúdo, bloqueio temporário ou banimento, conforme gravidade e reincidência.
